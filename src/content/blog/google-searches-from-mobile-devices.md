As of 2021, the percentage of people who search online through a mobile phone is approximately **54.8% globally**.

However, this number may vary depending on the location and demographic of the audience being studied. For example, in some countries or regions, mobile usage may be even higher.

Here are some additional statistics on mobile phone usage for online search:

- In the United States, 61% of Google searches are done from mobile devices.
- In China, 98% of internet users access the internet via mobile devices.
- In India, 79% of internet users access the internet via mobile devices.
- In the United Kingdom, 65% of internet users access the internet via mobile devices.
- In Japan, 66% of internet users access the internet via mobile devices.

It’s worth noting that these statistics are subject to change over time as technology continues to evolve and people’s habits shift.

## Why do people choose a mobile over a desktop when doing a Google search?

There are several reasons why people may prefer to use Google on a mobile device rather than a desktop computer:

- **Convenience:** Mobile devices are portable and can be accessed from anywhere, which makes it more convenient to use Google on the go.
- **Speed:** Mobile devices typically have faster load times than desktop computers, which can make searching on Google faster and more efficient.
- **Voice search:** Many mobile devices have built-in voice assistants, such as Siri or Google Assistant, that allow users to conduct searches using voice commands, which can be faster and more convenient than typing.
- **Touchscreen interface:** Mobile devices have touchscreen interfaces that allow for more intuitive and interactive searching experiences, such as swiping, tapping, and pinching to zoom in and out.
- **Personalization:** Mobile devices often allow for more personalized search experiences, such as using location data to provide local search results or accessing personalized recommendations based on previous search history and behavior.

Overall, the convenience, speed, voice search capabilities, touchscreen interface, and personalized search experiences offered by mobile devices make them a popular choice for searching on Google.

## How Google Search Console helps

A business website needs to follow Google Search Console advice for several reasons:

- **Better search engine visibility:** Google Search Console provides information about how Google crawls and indexes your website. By following the advice provided by Google, you can optimize your website for search engines, which can improve your website’s visibility in search engine results pages (SERPs).
- **Improved user experience:** Google Search Console provides insights into how users interact with your website, such as how long they stay on your site and how many pages they visit. By following the advice provided by Google, you can improve your website’s usability and user experience, which can lead to increased engagement, higher conversion rates, and greater customer satisfaction.
- **Faster issue resolution:** Google Search Console alerts you to any issues on your website, such as broken links or crawling errors. By following the advice provided by Google, you can quickly identify and resolve any issues, which can prevent them from negatively impacting your website’s search engine rankings or user experience.
- **Increased website security:** Google Search Console provides security alerts for any potential security issues on your website. By following the advice provided by Google, you can ensure that your website is secure and protected from hacking and other security threats.

Following the advice provided by Google Search Console can help businesses optimize their website for search engines, improve user experience, resolve issues quickly, and ensure website security.

## Google Search Console helps with mobile responsiveness in several ways

- **Mobile usability reports:** Google Search Console provides mobile usability reports that show any issues with your website’s mobile responsiveness, such as content that is too wide for a mobile screen or clickable elements that are too close together. By addressing these issues, you can ensure that your website is optimized for mobile devices and provides a better user experience.
- **Mobile-friendly test:** Google Search Console also offers a mobile-friendly test that allows you to check if your website is optimized for mobile devices. The test provides recommendations for improving mobile responsiveness, such as using a responsive design or optimizing images for mobile devices.
- **Mobile-first indexing:** Google now uses mobile-first indexing, which means that Google crawls and indexes the mobile version of a website first. If your website is not optimized for mobile devices, it may not rank as well in mobile search results. By using Google Search Console to ensure your website is mobile-friendly, you can improve your website’s mobile search rankings.
- **Accelerated Mobile Pages (AMP):** Google Search Console provides reports on your website’s AMP pages, which are optimized for faster loading times on mobile devices. By optimizing your website for AMP, you can improve mobile responsiveness and provide a better user experience.

In summary, Google Search Console helps with mobile responsiveness by providing mobile usability reports, a mobile-friendly test, support for mobile-first indexing, and insights into AMP pages. By using these tools, businesses can ensure that their website is optimized for mobile devices and provides a better user experience on mobile.
